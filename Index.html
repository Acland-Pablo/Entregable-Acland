Entregable de Pablo Acland

Este sitio permite al usuario ingresar su nombre para iniciar sesión, ver una lista de productos disponibles dande un boton de agregar al carrito, tambien dispone de un search para buscar un producto en concreto, tambien hay un boton para acceder al carrito y ver los productos seleccionados, en el carrito se puede gestonar los productos y eliminar los que realmente no se querian, ademas igresando con el user "admin" se puede realizar una gestion del inventario.
